⚙ Live Connection Setup

This Version 3 is designed to use Firebase Realtime Database so the staff phone and TV can share the same queue over the internet.

1. Create a Firebase project.
2. Enable Realtime Database and Web app configuration.
3. Copy your Firebase web configuration into the firebaseConfig object in this file.
4. Deploy this HTML on a web host (for example Firebase Hosting, GitHub Pages, or another HTTPS host).
5. Open the same web address on the staff phone and TV. Both devices will then use the same live queue.

Important: The file currently contains placeholder Firebase settings. It will not become cross-device live until your Firebase configuration is added.
